Bienvenido/a al repositorio oficial de mi portafolio web personal en formato **One-Page**. Este proyecto representa mi carta de presentación técnica, diseñada para exhibir mi perfil multidisciplinario que combina las **Geociencias** (Geología) con el **Desarrollo de Software y Análisis de Datos**.

📌 **Sitio Web desplegado:** [yuritrojasmantilla.github.io/portfolio](https://yuritrojasmantilla.github.io/)

---

## 🎯 Objetivos del Proyecto

- **Estructura Semántica Sólida:** Uso estricto de etiquetas HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) para garantizar mantenibilidad, accesibilidad (a11y) y SEO óptimo.
- **Diseño Responsive First:** Interfaz completamente adaptativa probada en dispositivos móviles, tablets y laptops mediante CSS Grid y Flexbox.
- **Contraste y Accesibilidad Visual:** Paleta cromática en modo oscuro con contraste WCAG verificado, ofreciendo una experiencia cómoda a la vista.
- **Rendimiento y Carga Rápida:** Optimización de activos multimedia e inclusión de atributos como `loading="lazy"` para minimizar tiempos de respuesta.
- **Flujo de Trabajo Profesional:** Control de versiones bajo metodología **Git Flow** y registro de historia con **Conventional Commits**.

---

## 📐 Estructura de la Página (One-Page)

La arquitectura de la página está articulada en secciones intuitivas accesibles mediante el menú superior de navegación suave:

1. **Header / Navegación:** Identificador de marca personal y menú de navegación rápida fija (`sticky`).
2. **Inicio (Hero Section):** Presentación principal con resumen de perfil, botones de llamada a la acción (*CTA*) y estadísticas clave.
3. **Sobre mí:** Trayectoria profesional, enfoque en geociencias/programación y principios de trabajo.
4. **Proyectos Destacados:** Tarjetas interactivas con información sobre repositorios en SQL, RStudio y desarrollo web.
5. **Habilidades Técnicas:** Desglose interactivo de lenguajes de programación (`JavaScript`, `Java`, `C/C++`, `SQL`, `R`) y competencias geoscientíficas.
6. **Contacto:** Canales principales de contacto directo (Email, GitHub, LinkedIn).
7. **Footer:** Accesos de navegación secundaria y derechos de autor.

##  Flujo de Trabajo (Git Flow & Conventional Commits)

Este proyecto se construyó siguiendo buenas prácticas de control de versiones.

### Estándar de Commits (`Conventional Commits`):
Los commits del repositorio siguen el formato estandarizado:
- `feat`: Nueva funcionalidad añadida.
- `style`: Cambios en la capa de diseño, estilos (CSS) o formateo sin afectar lógica.
- `perf`: Mejoras en rendimiento o carga de activos.
- `docs`: Cambios o actualizaciones en la documentación (`README.md`).
